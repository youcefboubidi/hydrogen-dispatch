# 3D digital twin — Ghardaïa solar-hydrogen plant

An interactive 3D visualization of the plant's load flow over a representative
day, in the style of an ETAP load-flow run. **Every value shown is real** — it
comes from `../plant_data.js` (`window.PLANT_STATE`), which is generated by
`scripts/export_plant_state.py` from the validated pandapower load flow on the
real CAMS+ERA5 → PySAM PV. Nothing is hand-faked.

## Open it
Double-click `index.html` (needs an internet connection — three.js loads from a
CDN). Or serve the repo root: `python -m http.server` then browse to
`app/plant_3d/`.

## What you see
- The plant in 3D: utility grid (U1) → 11 kV bus → 2 MVA transformer (T1) →
  0.415 kV bus → solar array (PVA1, injects) and electrolyzer (ELY, draws).
- A **time slider + play/pause + speed** stepping through the day in 15-min steps.
- **Floating ETAP-style labels** over each device: bus voltages (pu, kV),
  transformer loading % and currents, grid power (import/export) and current,
  PV and electrolyzer power and currents — colour-coded green/amber/red against
  the network limits (0.95–1.05 pu, ≤100 % loading).
- **Animated power-flow** along the connections (direction by sign, colour by type).

## Regenerate the data
```
python scripts/export_plant_state.py    # rewrites ../plant_state.json and ../plant_data.js
```
